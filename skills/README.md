# Навыки

Навык это процедура одного этапа: когда применять, что на входе, шаги, итог, ворота. Агент читает только навык текущего шага. Общие правила лежат в `AGENTS.md` и `agent/` и здесь не повторяются.

| Навык | Этап | Когда | Готовность |
|---|---|---|---|
| `brief` | 1 | новый запрос | в работе |
| `intake` | 2 | есть материалы в `inbox/` или ссылки | в работе |
| `data` | 2 | среди материалов таблицы и выгрузки | в работе |
| `ux` | 2 | снимки экранов, записи, сам продукт | в работе |
| `research` | 3 | нужно закрыть вопросы | в работе |
| `interviews` | 3 | нужны интервью или модельные респонденты | в работе |
| `options` | 4 | картина собрана, нужен выбор | готов |
| `strategy` | 5 | вариант выбран | в работе |
| `review` | 6 | документы написаны | в работе |
| `decisions` | 7 | решение принято или вопрос «Что по решениям?» | в работе |
| `revise` | любой | появились новые данные | в работе |

Пока навык «в работе», этап выполняется по его описанию в `agent/workflow.md`.

## Как устроен навык

Папка `skills/<имя>/` с файлом `SKILL.md`. В начале файла имя и описание (поля `name` и `description`): по ним среды с поддержкой навыков находят его сами. В остальных средах агент открывает файл по таблице выше.

Разделы навыка: Когда, Вход, Шаги, Итог, Ворота, Частые ошибки, Пример. Объём до 120 строк. Образец: `options/SKILL.md`.

## Как добавить навык

1. Назови пользу: какой шаг без навыка получается хуже или дороже. Нет ответа: навык не нужен.
2. Скопируй структуру образца. Методику не пересказывай, ссылайся на `knowledge/`.
3. Ворота пиши так, чтобы их можно было проверить по файлам, а не по ощущению.
4. Добавь строку в таблицу выше и, если нужно, в таблицу процесса в `AGENTS.md`.
