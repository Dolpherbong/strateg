# Вопросы исследования

Задача `{{task}}`: записи Q. Вопрос нужен, только если ответ может изменить выбор: это пишется в поле «что изменит ответ». Формат: `agent/records.md`. Следующий номер: `python tools/strateg.py next Q`.

Вопрос, который перестал влиять на выбор, получает статус «снят». Вопрос, на который ответить не удалось, получает статус «пробел» и поле «чем грозит».
