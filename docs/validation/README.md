# Подтверждения

Здесь лежит то, на чём держатся цифры описания и `docs/evidence.md`, в объёме, который можно открыть из репозитория. Полные ходы сеансов сред сюда не входят: в них тексты чужих страниц и служебные данные машины автора.

| Файл | Что подтверждает | Как проверить самому |
|---|---|---|
| `brief-run.md` | главное демо по брифу МегаФона в Claude Code 19.11.2026: все 16 реплик руководителя и ответы агента дословно, время, цена, отказы разрешений, вызовы субагентов | повторить реплики в чистой копии папки с брифом в корне |
| `brief-audits/` | замечания к расчётам итогового документа по брифу; что агент сделал с каждым, в `projects/operator-n-family/tasks/01-family-devices/out/revision-2026-11-19-audit*.md` | запустить по очереди `calc_baseline.py`, `calc_options.py`, `calc_gaps.py` и `calc_strategy.py` из `projects/operator-n-family/tasks/01-family-devices/work/` и сверить с документом |
| `claude-code.md` | работу в Claude Code: три фразы сопровождения на готовом примере (три серии до и после правок) и полный путь новой задачи с настоящими субагентами; ходы, время, токены, оценка цены, отказы разрешений | открыть папку в Claude Code и повторить реплики из файла |
| `scenarios.md` | девять сценариев в Codex 12.11.2026: реплики человека, ответы агента дословно, итоги независимой проверки по файлам, найденные ошибки агента и где их причина в инструкциях | повторить реплики в чистой копии папки |
| `claims-check.md` | сверку 10 ключевых утверждений демо с первоисточниками 16.11.2026: место, цитата, сила пересказа, расчёты | открыть адреса из таблицы; расчёты `python projects/operator-n-travel/tasks/01-travel-esim/work/run_calculations.py --check` |
| `comparison/` | сравнение с обычным чатом: запрос (`chat-prompt.txt`), ответ чата (`chat-answer.md`), протокол с каталогами утверждений, выборками и зерном (`protocol.md`), итоговая таблица (`compare.md`) | пересчитать по протоколу; документы агента для сравнения лежат в `projects/operator-n-travel/tasks/01-travel-esim/work/before-S18-*.md.txt` |

Что здесь не доказывается: качество стратегии для настоящей компании (оператор вымышленный, руководителя играла модель), спрос и исполнение услуг конкурентов, независимость оценок моделей от их создателей. Оценки по критериям задания в отдельных сеансах моделей это мнение моделей, а не балл жюри.

Архивные снимки `work/before-*.md.txt` и `work/archive/` в проектах хранят тексты документов на момент снимка для сверки строк; ссылки внутри них относились к раскладке файлов того времени и могут не открываться.
