Что подтверждено:
- Полный путь от размытого запроса до записанного решения с ответственным, сроком и условием пересмотра в среде, отличной от Codex, и на модели среднего класса: около 14 минут работы агента, около 3,4 $ по ценам API.
- Субагенты запущены по-настоящему: три вызова (критик на этапе 4, проверяющий источников и критик на этапе 6) видны в журнале сеанса среды как отдельные агенты типа `critic` и `source-checker` со своими ходами. Критик на этапе 4 изменил рекомендацию.
- Остановки для человека сработали все четыре плюс «хватит или глубже»; решение не записано до «да» человека.

Что не так и названо честно:
- Вход критика этапа 6 и вход и ответ проверяющего источников в `work/` не сохранены (есть только `critic-6-answer.md` и строки журнала), хотя правило требует и то и другое. Вызовы подтверждаются журналом среды, а не файлами задачи.
- Официальные страницы операторов не открылись (ошибки 401 и 404), агент брал сведения из пересказов с надёжностью B и C и пометил это; проверяющий источников сверил числа, хвост одной цитаты (E14) остался непроверенным, это обязательство K6.
- Пять отказов разрешений на шаге 6: агент запускал свой расчёт `work/economics.py` через `cd ... &&` и абсолютный путь, такие команды разрешение не покрывало. Он посчитал вручную по той же формуле и прямо сказал об этом; перепроверка вынесена в обязательство K6.
- Токены в журнал задачи агент не записал: среда их ему не показывает. «Сколько потратили?» ответил временем и 0 ₽ платных действий; цена выше взята из данных среды.

## 3. Сколько это стоит и сколько влезает в подписку

Подписка не показывает цену одного запроса, поэтому всё ниже это оценка по ценам API, а не списание.

| Работа | Среда и модель | По ценам API |
|---|---|---|
| Полный путь новой задачи (раздел 1) | Claude Code, Sonnet | около 3,4 $ |
| Демо eSIM, 8 реплик | Codex, gpt-6.1-sol | около 3,8 $ |
| Вторая задача, 6 реплик | Codex, gpt-6.1-sol | около 2,7 $ |
| «Где мы?», «Насколько прочно?» | Claude Code, Opus | 0,24-0,39 $ |
| Пересмотр по новым данным | Claude Code, Opus | 0,39-1,32 $ |

Ёмкость подписки Claude Max прикинута по данным самой машины: за неделю с 11.11.2026 все работы автора с моделями Claude по ценам API (подсчёт `ccusage` по локальным журналам) составили около 700 $, и это 72-73% недельного лимита по счётчику подписки. Значит, недельный лимит соответствует примерно 600-1000 $ по ценам API (разброс из-за того, как в общий лимит входит отдельный лимит модели Fable). Отсюда порядок величины:
- полных задач на Sonnet, как в разделе 1: около 170-290 в неделю;
- коротких ответов сопровождения на Opus: около 1 500-4 000 в неделю;
- до этого чаще упрётся пятичасовое окно: за время полного пути и параллельной работы автора оно выросло на 13 пунктов.

Это прикидка на одной машине и одной неделе, а не тариф. Для Codex такой подсчёт не сделан: счётчик лимита его подписки в консольном режиме не виден.
