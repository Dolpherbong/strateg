1. **Сдавать жюри как есть нельзя.** Обоснован первый квартал подготовки, а O3 остаётся условным кандидатом на пилот.
2. **Обязательно** пересчитать набор уникальных групп и сроки, определить мощность для правила расширения и добавить исход при вреде.
