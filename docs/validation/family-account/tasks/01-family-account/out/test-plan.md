# План проверки

- выбранный вариант: O3
- дата: 2026-11-16
- пересмотрено: нет

Итог этапа 5: как мы узнаем, что ставка сыграла или не сыграла. Мерило: `knowledge/strategy.md`, раздел 5. По плану должно быть можно прийти к выводу «не сработало».

Порядок, который нельзя менять: (1) назвать в N владельца среза и получить числа для расчёта порога (абоненты в группах, маржа, отток, смета); без названного владельца проверка не начинается, (2) пересчитать порог по ним, (3) только потом смотреть причины ухода и интервью. Пока чисел N нет, действуют ориентиры E26, а число 31% совету как порог не показывается: показывается формула и входы. Человек подтверждает пороги до начала сбора. «0 ₽» значит «без платных действий»: время аналитиков, команды и юриста N не нулевое.

## Что проверяем

Начиная с самой шаткой:

1. Семейная группа повышает удержание [E19, гипотеза]. **Эту гипотезу проверка O3 не проверяет.** Срез покажет только, какая доля уходов связана с общим пакетом, то есть есть ли проблема; эффект самой функции измерит только пилот с контрольной группой, и то не сразу, потому что отток редкий и медленный [O4, гипотеза]. Это сказано совету прямо.
2. Пожилые родители примут управление через приложение ребёнка [E20, гипотеза].
3. Согласие по SMS и договор за ребёнка закрывают правовой вопрос [E9, E18; нормы по первоисточнику не проверены, Q6].
4. Срез данных у N доступен [гипотеза, O3].
5. Минимальная версия укладывается в силы команды [гипотеза, E23].

## Ожидаемое изменение

Если за 4 недели выполнить проверку O3 (срез, 5-8 интервью, правила, оценка трудоёмкости), то число открытых вопросов Q3 (в части «есть ли проблема»), Q5, Q6 снизится с 3 до 0 [C4, C5]. Исходное число: три открытых [C4, C5]. Целевое: ноль закрыто с понятной уверенностью, срок 4 недели [гипотеза].

Ответ «проблемы нет» тоже успех проверки: он экономит вложения. Провалом считается «не знаем» по любому из трёх вопросов в конце срока.

## База сравнения

Состояние до проверки: три вопроса открыты [C4, C5]. Отток N: не знаем, ориентир 2,0% в месяц [E24], узнать из среза. Контрольной группы у проверки нет: она не меняет продукт. Интервью сравниваем между собой по двум группам: родители детей и пары «ребёнок и пожилой родитель». Пилот с контрольной группой (O4) относится к следующему шагу, и его база записывается отдельно до запуска.

## Правило решения

<!-- без опоры -->
Записано до сбора данных. Условия:

- (1) срез: доля уходов, связанная с общим пакетом и семьёй, не ниже порога, пересчитанного по числам N (по ориентирам 31% [E26]). Три исхода: выполнено, не выполнено, не оценено (среза нет).
- (2) спрос: не менее двух третей пар из интервью готовы подключиться, считая отдельно родителей детей (2а) и пары с пожилым родителем (2б); (2) выполнено, если выполнено (2а) или (2б). Это заявленное намерение, оно слабо предсказывает использование, поэтому оно открывает пилот, а не запуск.
- (3) силы: трудоёмкость минимума в пределах ресурса, названного руководителем продукта до оценки.

Таблица разбирает все исходы, пересечений нет:

| (1) | (2) | (3) | Решение |
|---|---|---|---|
| выполнено | да | да | **продолжаем**: пилот O4 с контрольной группой (только для (2а), если (2б) не выполнено); база и ранний показатель пилота записываются до запуска. O5 рассматриваем дополнительно, если не менее половины пар с пожилым родителем ясно просят защиту |
| выполнено | да | нет | **меняем**: сужаем минимум и повторяем оценку, решение переносим |
| выполнено | нет | любое | **меняем**: возвращаем совету с двумя вариантами: интервью по другой выборке или O2 с условием пересмотра |
| не выполнено | да | любое | **меняем**: по ориентирам экономика не сходится; совету даём выбор: пилот только как мера паритета без ожидания удержания, либо O1 |
| не выполнено | нет | любое | **останавливаем**: O1 или O2 с записанным условием пересмотра |
| не оценено | да | да | **меняем**: O4 с записанным условием остановки, совету прямо сказано, что отток не измерен |
| не оценено | да | нет, или (2) нет | **останавливаем**: O1 или O2 с условием пересмотра |

Остановка самой проверки: к концу 6-й недели нет среза и нет начатых интервью, тогда останавливаем и сообщаем совету, что проверка не состоялась. Если правовая сверка показала, что согласие по SMS не годится, пилот перепроектируется до запуска, а не после. Граница правовой проверки: мы сверяем по первоисточникам и пишем список вопросов юристам N; заключение юриста вне рамки [бриф].
