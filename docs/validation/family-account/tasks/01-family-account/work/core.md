# Ядро стратегии (этап 5, вариант O3)

- дата: 2026-11-16
- выбор человека: O3, «Выбираю вариант, который ты рекомендуешь», 2026-11-16

## Три строки

- **Диагноз.** У трёх крупнейших операторов функция уже есть [C1], но выгода в деньгах не доказана [C4], а пожилые родители из запроса не имеют опоры [C5]. Главная трудность: решать нужно сейчас, а знаний про отток и пожилых нет.
- **Направляющий выбор.** Сначала узнать, потом строить: 3-4 недели проверки без разработки и без платных действий, затем решение по порогам, записанным до просмотра данных [O3].
- **Согласованные действия.**
  1. Записать пороги и порядок их расчёта до сбора данных (пересчёт порога под числа N).
  2. Срез данных N: причины ухода, обращения про общий пакет, отток [Q3].
  3. 5-8 интервью с парами «взрослый ребёнок и пожилой родитель» и родителями детей [Q5].
  4. Проверка правил по первоисточникам и оценка трудоёмкости минимума силами команды N [Q6].
  5. Решение совету: O4, O5 или O1/O2 по порогам.

Вычеркнуто как подходящее к любому выбору: «следить за конкурентами» и «улучшать приложение вообще».

## Ответы на семь вопросов согласованности

1. Диагноз опирается на сведения? Да: C1, C4, C5 и их основания E1, E8, E11, E14, E18, E19, E20.
2. Понятно, от чего отказались и почему? Да: четыре отказа в `out/product-strategy.md`, раздел «Сознательные отказы».
3. Аудитория одна? Да: взрослый-организатор 35-44 лет с детьми и, возможно, пожилыми родителями, в обоих документах.
4. У каждого обещания подтверждение? Да: два обещания в состоянии «будет к запуску при решении о пилоте», остальные из сообщения убраны; «нет» не осталось.
5. Экономика сходится при названных условиях, слабое условие названо? Да, с оговоркой: в базовом сценарии сходится при доле связанных уходов не ниже 31% [E26]; в осторожном не сходится; ломающее допущение: размер группы абонентов и стоимость разработки [E21, E23].
6. По плану можно прийти к выводу «не сработало»? Да: у правила решения есть порог остановки и срок, при котором проверка считается проваленной.
7. Руководитель поймёт суть по первому разделу каждого документа? Да, проверено при написании.
