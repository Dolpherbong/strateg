# Черновые варианты (рамка для вопросов, не записи O)

Это набросок для этапа 3. Настоящие варианты O оформит этап 4.

1. **Оставить как есть.** В приложении N нет семейного аккаунта. Условие победы: абоненты N не уходят из-за этого, а у конкурентов функция не даёт им преимущества.
2. **Закрыть направление.** Не возвращаться к теме, пока не появятся данные. Условие: у функции нет эффекта на удержание и она не нужна даже как минимум.
3. **Минимальный семейный аккаунт.** Взрослый добавляет до 3-5 номеров, делится общим пакетом, получатель подтверждает участие. Условие: это закрывает базовый спрос и стоит немного.
4. **Полный семейный аккаунт с ролями.** Роли «ребёнок» и «взрослый», родительский контроль, защита от мошенников для пожилых. Условие: роли и защита дают реальную ценность, а не просто копируют конкурента.
5. **Проверка на малой группе.** Запуск минимальной версии для части абонентов с целью измерить удержание, затем решение о роли и защите. Условие: эффект можно измерить за разумный срок.
