## Протокол в пяти строках

1. Единица: существенное проверяемое утверждение о мире; независимые свойства перечислений разделены, цена пакета проверяется вместе с его объёмом и сроком.

3. Одинаковые утверждения объединены; пометки гипотез учитываются, включая явно объявленную область таблицы; ссылка засчитывается в той же смысловой единице, в таблице только в той же ячейке.

Сокращения: св = summary, си = situation, оп = options, пр = product-strategy, ко = comms-strategy, пл = test-plan. Число после сокращения = строка. Число после точки = ячейка таблицы без технического разделителя. Вхождения перечислены через точку с запятой. Ссылки на C раскрываются через выводы situation и далее E, ссылки E через evidence и sources. Ссылки Q сами по себе обозначают вопрос и не дают внешнего адреса. Внутренние D, K и результаты выполнения работы исключены вместе с соответствующими утверждениями.

Пакет с ценой, объёмом и сроком является одним тарифным утверждением, а независимые функции пакета разделены. Одна цена в ячейке без ссылки не наследует ссылку из другой ячейки. ## Ч3, полный счёт числовых предъявлений

Единица здесь числовое значение, а не уникальное утверждение. Границы диапазона считаются двумя значениями; числительные словами тоже учитываются, например семидневный пакет и пять наблюдений. Десятичное число и цена с пробелом внутри являются одним значением. Число с повтором учитывается в каждом предъявлении. Исторические годы/даты, номера E/S/C, названия T2/1GLOBAL, термины второй профиль/режим двух линий исключены как контекст и обозначения. Указанный возраст исследования больше года учтён как количественное ограничение давности. Числа из проектов порогов, будущих сроков, бюджета, требований продукта и условных примеров исключены.

Самостоятельные общие утверждения об ограничениях метода включены по тому же правилу, что и в Ч1. ## Ограничения

1. Ручная разметка одним оценщиком: границы существенного утверждения, объединение повторов, область пометки и смысловая связь ссылки требуют суждения. Особенно чувствительны общие методические утверждения и собственные номера E без адреса. Каталоги, все места и проверка чувствительности Ч3 оставлены для независимой переразметки.
2. 40 утверждений и 10 сверок не описывают все свойства результата. Утверждения внутри документа связаны между собой и часто опираются на одну страницу; интервалы являются приближёнными и не учитывают корреляцию, ручной выбор границ каталога и конечную базу. Два текста относятся к одной задаче и одному прогону, обобщения на модели и способы работы не следуют.
3. Сверка источников выполнена позже снимков 11.11.2026. Коммерческие страницы меняются, встречаются HTTP 429 и частичная доступность. Совпадение с витриной не проверяет оплату, связь и репрезентативность опроса; отсутствие адреса не доказывает ложность. B состоит из шести файлов, A из одного, но повторы и исключения применены одинаково.

def table(text: str, start: str, end: str) -> list[list[str]]:
    """Extract a Markdown table between named boundaries."""
    part = text.split(start, 1)[1].split(end, 1)[0]
    return [
        [cell.strip() for cell in line.strip().strip("|").split("|")]
        for line in part.splitlines()
        if line.startswith("| ") and not line.startswith(("| ID ", "|---", "| Объект "))

def wilson(k: int, n: int) -> tuple[float, float]:
    """Calculate a two-sided 95 percent Wilson interval."""
    z = 1.959963984540054
    den = 1 + z * z / n
    center = (k / n + z * z / (2 * n)) / den
    half = z * math.sqrt(k / n * (1 - k / n) / n + z * z / (4 * n * n)) / den
    return (100 * (center - half), 100 * (center + half))

def check_samples(text: str) -> None:
    """Verify random selection and both Ch1 counts."""

        ("A", "### Каталог B", "### B, агент", 122, 2026111201, 14, 19),
