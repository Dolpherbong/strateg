# База знаний

Методика, которая не зависит от конкретного проекта. Агент читает файл только по ссылке из навыка или когда сомневается в качестве результата.

| Файл | О чём | Кто ссылается |
|---|---|---|
| `evidence.md` | виды сведений, надёжность источников, перекрёстная проверка, ловушки, слова неуверенности | `intake`, `research`, `review`, `revise` |
| `strategy.md` | что отличает стратегию от списка желаний, состав стратегий и плана проверки, сверка обещаний | `options`, `strategy`, `review` |

## Чего здесь нет

- Фактов о рынке, компаниях и продуктах. Они устаревают и живут в реестрах проекта с источником и датой.
- Правил поведения агента. Они в `AGENTS.md` и `agent/`.
- Процедур. Они в `skills/`.

## Как добавить знание

1. Один файл на одну тему, до 150 строк, своими словами.
2. Чужая идея называется по автору, чужой текст не копируется.
3. В начале файла одна фраза: для чего он и кто на него ссылается.
4. Добавь строку в таблицу выше и ссылку из навыка, которому это знание нужно. Знание без ссылки из навыка никто не прочитает.
5. То, что верно только для одной отрасли или компании, клади в проект, а не сюда.
