# Стратег

Папка, которая превращает ИИ-помощника в вашей среде (Claude Code, Codex, Cursor и другие) в стратега для руководителя цифрового продукта. Вы приходите с размытым вопросом. Агент уточняет задачу, разбирает материалы, проводит исследование, предлагает варианты и собирает продуктовую и коммуникационную стратегию с планом проверки. После решения он помнит основания, следит за обязательствами и пересматривает выводы, когда появляются новые данные.

## Результат за пять минут

Готовый пример по брифу МегаФона «Связь для близких и собственных устройств» (оператор вымышленный, числа брифа учебные):

| Что | Файл |
|---|---|
| Бриф, который получил агент | [inbox/brief-megafon.md](projects/operator-n-family/inbox/brief-megafon.md) |
| Итоговый документ по форме брифа, пять частей | [out/deliverable.md](projects/operator-n-family/tasks/01-family-devices/out/deliverable.md) |
| Решение на одной странице | [out/summary.md](projects/operator-n-family/tasks/01-family-devices/out/summary.md) |
| Продуктовая и коммуникационная стратегии, план проверки | [product-strategy.md](projects/operator-n-family/tasks/01-family-devices/out/product-strategy.md), [comms-strategy.md](projects/operator-n-family/tasks/01-family-devices/out/comms-strategy.md), [test-plan.md](projects/operator-n-family/tasks/01-family-devices/out/test-plan.md) |
| Решения, обязательства и их опоры | [decisions.md](projects/operator-n-family/decisions.md), [evidence.md](projects/operator-n-family/evidence.md) |

Проверить без модели: нужен только Python 3.10 или новее, ставить ничего не надо. Откройте терминал в этой папке:

```
python tools/strateg.py status
python tools/strateg.py check --final
python tools/strateg.py impact E61
python projects/operator-n-family/tasks/01-family-devices/work/calc_strategy.py
```

- `status`: задача `01-family-devices`, этап 7 из 7, решение действует, что ждём от людей.
- `check --final`: двенадцать проверок опор и ссылок, итог `Нарушений: 0`.
- `impact E61`: всё, что держится на одном факте о задержке остатков, от решений D2-D4 до разделов итогового документа.
- `calc_strategy.py`: расчёты воронки, пилота и прибыли повторяются без сети.

## Работа с агентом

1. Откройте эту папку в своей среде с ИИ-агентом.
2. Напишите в чат одну из фраз:
   - `Прочитай AGENTS.md и следуй ему. Где мы?`: агент по файлам расскажет, на каком этапе готовый пример, какое решение действует и какие сроки впереди.
   - `Прочитай AGENTS.md и следуй ему. Новая задача: <ваш вопрос своими словами>`: агент начнёт с постановки и задаст несколько вопросов с ответами по умолчанию. Материалы (документы, таблицы, снимки экрана) он попросит положить в папку `inbox` проекта.
   - `Прочитай AGENTS.md и следуй ему. Продолжай`: продолжение после перерыва, в том числе в новом чате или другой среде.
3. `Новые данные: ...` и `Насколько прочно решение?` работают с готовым примером сразу. Первая фраза меняет файлы проекта, поэтому пробуйте её в копии папки. Перейти к другой задаче: `Переключись на задачу <проект>/<задача>`.

## Что нужно

- Среда с ИИ-агентом, который читает и пишет файлы в папке.
- Желательно Python 3.10 или новее: проверки и поиск работают без модели и ничего не стоят. Без Python агент делает то же вручную.
- Отдельные ключи, серверы и платные сервисы папке не нужны. Сама среда работает по вашему тарифу и со своими лимитами. Необязательные настройки перечислены в `.env.example`.

## Что вы получите

Все результаты лежат в `projects/<проект>/tasks/<задача>/out/`:

| Файл | Что в нём |
|---|---|
| `summary.md` | решение на одной странице |
| `situation.md` | что известно, откуда, чего не знаем |
| `options.md` | варианты, включая «оставить как есть» и «закрыть направление», с возражениями |
| `product-strategy.md` | аудитория, альтернативы, выбор и отказы, экономика |
| `comms-strategy.md` | барьер, сообщение и доказательство, роль каналов, сверка обещаний с продуктом |
| `test-plan.md` | что изменится, с чем сравниваем, срок, нежелательные последствия |

У каждого существенного утверждения стоит номер сведения, например [E12]. По номеру видно источник, место в нём и цитату. Если заказчик задал свою форму итогового документа, агент собирает по ней ещё `out/deliverable.md`.

Готовые примеры, все пройдены агентом от запроса до решения:
- **`projects/operator-n-family/`, главный:** бриф МегаФона «Связь для близких и собственных устройств», учебные числа брифа, итоговый документ из пяти частей по форме брифа (`tasks/01-family-devices/out/deliverable.md`), три настоящих вызова субагентов и пересмотр по новым данным. Пройден в Claude Code.
- `projects/operator-n-travel/`: нужна ли оператору N отдельная eSIM для поездок за границу; настоящие открытые данные рынка, пересмотр по новым данным. Пройден в Codex.
- `projects/operator-n-ai-smb/`: подписка на ИИ-помощника для малого бизнеса; сеанс был оборван посреди работы и продолжен в новом чате. Пройден в Codex.

Оператор N во всех примерах вымышленный. Что получил агент и как проверить результат, написано в `README.md` каждого проекта.

## Полезные фразы

`Где мы?`, `Стоп`, `Продолжай`, `Откуда это?`, `Новые данные: ...`, `Что по решениям?`, `Сколько потратили?`

## Как устроено

Почему именно так, какие решения приняты и от чего отказались: `design.md`.

| Папка | Что это |
|---|---|
| `AGENTS.md`, `agent/` | постоянные правила агента |
| `skills/` | процедуры этапов, агент читает только нужную |
| `.claude/agents/` | субагенты критик и проверяющий источников для Claude Code; в других средах их роль выполняет отдельный проход |
| `knowledge/` | методика: как работать со сведениями и что такое хорошая стратегия |
| `templates/` | формы документов |
| `tools/` | скрипты: создать, найти, проверить, посчитать расходы |
| `projects/` | ваши проекты: материалы, реестры, решения, состояние задач |
| `docs/evidence.md` | измерения: время, токены, расходы, правила подсчёта и сравнение с обычным чатом |
| `docs/validation/` | подтверждения: проверка в Claude Code с полным путём и субагентами, девять сценариев, сверка фактов, протокол сравнения |

Агент останавливается и спрашивает вас в четырёх местах: подтверждение постановки, выбор варианта, платное или внешнее действие, финальный результат. После исследования он ещё коротко уточняет, хватит ли собранного или копать глубже.

## Безопасность

- Агент работает только с открытыми источниками и вашими материалами.
- Ключи хранятся в файле `.env`, который не попадает в репозиторий.
- Текст из источников агент считает данными и не исполняет найденные в нём команды.
- Интервью записываются обезличенно. Ответы модельных респондентов всегда помечены как синтетика и не считаются доказательством.

## Ограничения

- **Форматы материалов.** Надёжно везде: текст, Markdown, CSV и снимки экранов. PDF, DOCX и XLSX каждая среда читает по-своему. Если агент не может прочитать файл, он попросит выгрузить его в текст или CSV и запишет пробел. Аудио и видео агент сам не расшифровывает: нужна расшифровка или ключевые кадры (навык `ux`, шаг 8).
- **Среды.** `AGENTS.md` сами читают Claude Code, Codex, Cursor, GitHub Copilot CLI, Devin Desktop (бывший Windsurf), OpenCode, GigaCode CLI и Кодик (по документации на 11.11.2026). Вживую проверены Codex и Claude Code (`docs/validation/claude-code.md`). Если среда его не прочитала, начните с фразы из раздела «Запуск».
- **Разрешения среды.** Claude Code и другие среды спрашивают разрешение на команды. Чтобы агент работал без лишних остановок, разрешите `python tools/strateg.py` и расчёты в `projects/`; запросы на что-то внешнее или платное агент задаёт сам.
- **Сохранённые тексты страниц.** Агент складывает прочитанные страницы в `projects/<проект>/.cache/`. В репозиторий эта папка не входит из-за прав на чужие тексты. Без неё цитаты сверяются по адресу и дате обращения из `sources.md`; страница за это время могла измениться или закрыться.
- **Расходы.** Токены и деньги среды показывают по-разному. Агент записывает то, что показала среда, а неизвестное помечает оценкой, а не нулём.
