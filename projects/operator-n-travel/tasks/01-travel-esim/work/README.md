# Воспроизводимые расчёты

Запуск из корня проекта, Python 3.10+, только стандартная библиотека:

```powershell
python projects/operator-n-travel/tasks/01-travel-esim/work/run_calculations.py --check
```

| Вход | Паспорт | Скрипт | Выход |
|---|---|---|---|
| outbound-2025.csv | outbound-2025-passport.md | scale_2025.py | scale-2025.json [E52, E53] |
| prices.csv | prices-passport.md | calc_prices.py | public-checks.json, roaming-plan-comparison.json [E28, E73] |
| economics-inputs.csv | economics-passport.md | calc_economics.py | economics-results.json, [economics.md](economics.md) [E83, E84] |

CSV уже зафиксированы: скрипты их только читают. Кэш страниц, реестры, браузер и сеть для арифметики не нужны. `--check` переносит только перечисленные CSV и расчётные скрипты во временную папку, делает два прогона и сравнивает выходы побайтно с основным прогоном. Дополнительно проверяет замещение, безубыточность и ранее сверенные итоги.

Для отдельной сверки старых цитат, если сохранённые снимки доступны:

```powershell
python projects/operator-n-travel/tasks/01-travel-esim/work/verify_and_compare.py --verify-quotes
```

Этот необязательный режим читает реестр и `.cache`, а при отсутствии снимка документа — его исходный файл в inbox/. Пишет `quote-checks.json` в дополнение к расчётам. Недоступные источники отмечаются отдельно; при них или несовпадении цитаты код завершения 1. Без флага `verify_and_compare.py` считает цены из CSV. Проверка цитат не подтверждает текущую продажу и не является частью воспроизведения арифметики.

`revise_s18.py`, `accept_s19.py`, `apply_review.py` — исторические одноразовые сценарии изменения документов; **повторно не запускать**. Расчёт 128 ₽ перенесён из `revise_s18.py` в `calc_prices.py`. Старые редакции сохранены в `before-*.txt`; `inspect_beeline.py` — историческая попытка просмотра, для расчётов не нужен.

Все входы учебной экономики помечены гипотезами; закрытых значений N нет. Учебная записка не выполняет K7 и не меняет D2. [E76, E77, E78, E79, E80, E81, E82, D2, K7]

`edit_delivery_2026_11_12.py` — исторический сценарий оформления этой редакции, содержит промежуточный снимок расходов. **Повторно не запускать**: это не расчётный скрипт и он перезапишет текст документов. Итог проверки этой редакции — в [quality-edits-2026-11-12.md](quality-edits-2026-11-12.md).
