# Пример: eSIM для поездок за границу, оператор N

Оператор N вымышленный. Рынок, цены конкурентов и статистика настоящие и открытые.

## Задача руководителя, дословно

«У нас в операторе N снова обсуждают отдельную eSIM для поездок за границу. Конкуренты уже предлагают что-то похожее, а мы пока продаём обычный роуминг. Посмотрите, нужен ли нам такой продукт и кому он вообще будет полезен. Хочется понять, стоит ли вкладываться в запуск или лучше обойтись тем, что уже есть».

## Что получил агент

- Только этот запрос и ответы руководителя в разговоре. Своих документов, таблиц и внутренних данных у руководителя не было.
- Сообщения руководителя, на которые опираются решения, сохранены дословно в `inbox/`: приёмка и решение, новые данные о цене роуминга, подтверждение уточнения.
- Позже руководитель положил в `inbox/screens/` восемь снимков открытых страниц покупки eSIM у билайна и МТС, снятых 12.11.2026 без входа и оплаты. Это вырезки полных страниц по высоте.
- Всё остальное агент нашёл сам в открытых источниках: сайты операторов, Росстат, отраслевые обзоры. Полный перечень с адресами и датами обращения в `sources.md`.

## Где результат

`tasks/01-travel-esim/out/`, начинать с `summary.md`. Рядом варианты, продуктовая и коммуникационная стратегии, план проверки, отчёт о пересмотре по новым данным и история редакций сводки. Разбор экранов конкурентов и учебные сценарии экономики: `tasks/01-travel-esim/work/`, файлы `ux-travel-esim-screens-2026-11-12.md` и `economics.md`. Ход работы и сбои: `tasks/01-travel-esim/journal.md`. Реестры проекта: `sources.md`, `evidence.md`, `decisions.md`.

## Как проверить

Из корня репозитория:

```
python tools/strateg.py check --project operator-n-travel --task 01-travel-esim --final
python tools/strateg.py impact E72 --project operator-n-travel
python tools/strateg.py find E29 --project operator-n-travel
```

Расчёты масштаба, цен и учебной экономики повторяются из CSV без сети и сохранённых страниц:

```
python projects/operator-n-travel/tasks/01-travel-esim/work/run_calculations.py --check
```

Первая команда прогоняет двенадцать проверок структуры и опоры. Вторая показывает, какие выводы, разделы и решения зависят от одного сведения о новой цене роуминга. Третья выводит запись факта с местом и цитатой.

Сохранённые тексты страниц (`.cache/`) в репозиторий не входят из-за прав на чужие тексты, поэтому цитаты сверяются по адресам из `sources.md`.
