# Пример: подписка на ИИ-помощника для малого бизнеса, оператор N

Вторая задача, из другой области. Оператор N вымышленный, данные открытые. Сеанс агента был принудительно оборван посреди исследования и продолжен в новом чате по слову «Продолжай».

## Задача руководителя, дословно

«Мы в операторе N думаем, не сделать ли подписку на ИИ-помощника для малого бизнеса: ответы клиентам, тексты, простая бухгалтерия. Многие уже пользуются чат-ботами бесплатно. Есть ли тут деньги для нас или это не наша история?»

## Что получил агент

- Запрос, подтверждение постановки, решение и дату старта теста: всё сохранено дословно в `inbox/`. Своих документов и внутренних данных у руководителя не было.
- Остальное агент нашёл в открытых источниках, перечень в `sources.md`.

`tasks/01-ai-subscription/out/`, начинать с `summary.md`. Расчёты экономики по сценариям лежат в `tasks/01-ai-subscription/work/` и повторяются запуском скриптов.
