# Критик этапа 6

- дата: 2026-11-19
- средство: субагент «критик», чистый контекст, без переписки

## Вход

Файлы: `brief.md`, `out/situation.md`, `out/options.md`, `out/product-strategy.md`, `out/comms-strategy.md`, `out/test-plan.md`; реестр `evidence.md` только для проверки ссылок.

Задание: «Ты сильный противник этой рекомендации. Назови пять самых сильных возражений по убыванию силы. У каждого: место в документе (файл и раздел), почему вывод сильнее оснований, что бы тебя переубедило. Ищи также противоречия чисел между документами и места, где план проверки не может прийти к выводу «не сработало». Ответ до 700 слов.»

## Ответ (сжато, по пунктам критика)

1. **Экономика сама предсказывает, что пилот не пройдёт порог.** Порог 5 п. п. взят из мощности выборки [E38], а не из ожидаемого эффекта. Базовый сценарий [E51], сравнённый с 5 040 ограничениями [E37], даёт около 1,4 п. п. Переубедит расчёт ожидаемого снижения из тех же допущений.
2. **План почти не может сказать «не сработало».** Интервал при 539 группах в ветке около ±3,7 п. п. Продления ничем не ограничены. Для снижения на 3,7-5 п. п. с интервалом без нуля правила нет. Для доппакетов граница не задана.
3. **Сроки расходятся.** При пороге 60 групп в неделю набор 1 078 групп занимает 18 недель, это больше «крайних 16» [E39]. Оценка уходит в октябрь, а прогноз активности [E49] исходит из расширения с октября.
4. **Выбор сигнала вместо изменения условия пакета и «как есть» не обоснован.** Решающие числа гипотетические [E33, E39, E41, E42], цена обоих путей неизвестна.
5. **Польза в активности отчасти создаётся самой метрикой** [E12]. +169 (не больше 441) это малая доля разрыва. Порога по активности нет. Удержание на выборке пилота не проверить.

## Решения

1. **Частично исправлено.** Добавлена верхняя оценка ожидаемого снижения 3,6-7,2 п. п. при исходных 12 % [E53]. Порог требует, чтобы вовремя действовало не меньше 42 % организаторов. В документах прямо сказано, что пилот может не пройти. Сравнение критика с 5 040 неточно: в E51 сценарии считаются от подходящих групп и при эффекте на уровне порога, это теперь записано в тексте E51.
2. **Исправлено.** Правило решения переписано таблицей всех исходов. Продление разрешено один раз, не больше 8 недель. Для снижения ниже порога с интервалом без нуля решение «сигнал без расширения». Для доппакетов задана граница: больше трети предотвращённых ограничений. Ширина интервала посчитана: ±3,5-3,9 п. п. [E54].
3. **Исправлено.** Порог одобрения с расширением в плановом году поднят до 80 групп в неделю [E54]. При 60-80 пилот идёт без расширения в плановом году. Сроки «август-сентябрь» согласованы во всех документах.
4. **Не закрыто.** Записано в рисках продуктовой стратегии и в «Чего не знаем» сводки. Ответ прежний: деньги на разработку только после выгрузки, и оба пути оценивают одни и те же люди.
5. **Исправлено частично.** Добавлена разница веток только по передачам. Расширение по активности не решается. Удержание на выборке пилота названо непроверяемым, его оценят по ветке сравнения при расширении.
