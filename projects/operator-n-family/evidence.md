# Сведения

Реестр сведений проекта `operator-n-family`: записи E. Одно утверждение, одна запись. Вид обязателен: `факт`, `оценка`, `гипотеза`, `прогноз`, `синтетика`. Формат и поля по видам: `agent/records.md`. Мерило качества: `knowledge/evidence.md`. Следующий номер: `python tools/strateg.py next E`.

Записи не удаляются. Опровергнутая получает статус «устарело» и поле «заменено», ошибочная получает статус «отозвано» и поле «причина».

Все сведения из S1 это учебные условия заказчика, а не измеренные данные рынка.
